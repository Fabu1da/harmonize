### A. Vectorized Rule Application
```python
def apply_rules_vectorized(dataset: pd.DataFrame, rules: dict[str, Callable]) -> pd.DataFrame:
    result = pd.DataFrame()
    for target_col, rule_func in rules.items():
        result[target_col] = dataset.apply(lambda row: rule_func(row.to_dict()), axis=1)
    return result
```
